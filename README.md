# 마이옵티멀다이어트 28일 루틴 — 24시간 퀘스트 대시보드 (v17 · 개인 실사용 배포판)

참여자용 28일 루틴 체크보드 + **28일 최종 리포트** + 관리자 대시보드 웹앱입니다.
처음 링크를 여는 사람은 **`내 28일 기록 시작하기`** → 튜토리얼에서 닉네임·시작일·인바디를 넣으면 바로 자기 기록이 시작되고, 기록은 현재 기기 브라우저(localStorage)에 자동 저장됩니다.
'오늘' 화면은 **프로필·신체 요약(몸무게·골격근량·체지방량·내장지방) → 그날의 주차별 조언 카드 → 실시간 타이머 3개(공복 · 마지막 저녁식사 · 수면) → 오늘의 명언 → 시간대별 투두리스트(오늘의 퀘스트) → 기본으로 펼쳐진 세부 기록(인증사진) → 인바디·메모·피드백** 순서로 가볍게 구성했고,
28일 체크보드·주차별 인바디·**추천템**·관리자는 기존 기능을 그대로 유지하고,
**처음 보는 튜토리얼 탭**에서 시작 인바디를 입력하고 기본 규칙·주차별 허용/금기식품을 한 번만 읽으면 바로 시작할 수 있습니다.
빌드 없이 `index.html`만 열면 바로 동작하고, 데이터는 브라우저 localStorage에 저장됩니다.
나중에 Supabase/REST API로 바꿀 수 있도록 데이터·인증 레이어를 분리해 두었습니다.

---

## 1. 실행 방법

**가장 간단하게 (파일 열기)**
```
apps/my-optimal-diet/index.html 을 브라우저로 열기
```
- 크롬/사파리에서 더블클릭으로 열면 바로 사용할 수 있어요.
- 폰에서 보려면: 폴더를 웹 서버에 올리거나, PC에서 아래처럼 임시 서버를 띄우고 같은 Wi-Fi의 폰에서 접속하세요.

```
cd apps/my-optimal-diet
python3 -m http.server 8080
# PC: http://localhost:8080   /  폰: http://<PC의 IP>:8080
```

> `file://`로 열면 PWA 설치·서비스워커는 동작하지 않습니다(앱 기능은 정상). https 배포 시 자동 등록됩니다.

## 2. 데모 계정

| 구분 | 방법 |
|---|---|
| 카카오 로그인 버튼 | 지금은 **데모 모드** — 누르면 이 기기에서 시작하는 안내가 나옵니다 |
| 내 28일 기록 시작하기 | **이 기기의 '내 기록'**이 새로 열립니다 — 데모 인물(김유니)과 분리되어 이름·샘플 체크 기록이 섞이지 않고, 튜토리얼에서 닉네임·시작일·인바디를 넣으면 바로 시작돼요. (v15까지 데모 참여자에 붙어 있던 개인 세션은 첫 실행 때 `내 기록`으로 한 번 정리되고, 직접 넣은 인바디·메모·인증사진은 그대로 이어받아요) |
| 관리자 로그인 | 로그인 화면 → **관리자 로그인** → 관리자 코드 입력 (원클릭 버튼 없음) |
| 참여코드 입장 | 코드 **1234** (김유니) · 2751 (김서연) · 4813 (이지은) · 6302 (최하늘) |

데모 참여자 4명은 모두 **가상 인물·가상 수치**이며, 관리자 화면·참여코드 입장에서만 쓰입니다(개인 기록과 분리). 기본 데모 참여자(김유니)의 시작일은 처음 접속한 날이라 항상 **Day 1**부터 시작하고,
나머지 세 명은 관리자 대시보드 예시를 위해 가상의 지난 기록을 갖고 있습니다.
관리자 화면 → **기록 · 설정 → 기기 데모 기록 초기화**로 언제든 처음 상태(Day 1)로 돌릴 수 있어요.

> 관리자 코드는 `js/config.js`의 `demo.adminCode` 값입니다. 소스가 공개되는 데모라 코드도 함께 보이므로, 실제 서비스에서는 아래 7절처럼 서버 인증으로 막아야 합니다.

## 3. 화면 구성

### 참여자 (모바일 퍼스트, 하단 탭 5개 — 튜토리얼 / 오늘 / 보드 / 인바디 / 추천템)
0. **튜토리얼** — 처음 접속하면 이 탭이 먼저 열리고, **입력 저장하고 1일차 시작하기 →** 로 오늘 탭에 들어가면 다음부터는 오늘 탭이 기본이에요(언제든 다시 보고 수정 가능)
   - **01 내 정보 & 시작 인바디**: 닉네임 · **마이옵티멀다이어트 시작일(오늘/어제/일주일 전 빠른 선택 + 날짜 직접 선택 — 과거·미래 모두 가능)** · **성별(여성/남성, 기본 여성)** · 시작 체중 · 골격근량 · 체지방량 · 내장지방 레벨(1~20) 입력 + **입력 저장** — 저장하면 상단 프로필 · Day 1 인바디 · 단백질 권장량에 바로 반영
     - 시작일이 미래면 '오늘' 화면에 **`11월 28일 (토)부터 시작해요 · D-3`** 시작 전 안내가 뜨고, 과거면 그날부터 계산한 **Day N**으로 이어가요(입력한 날짜 옆에 `오늘은 Day 6 (1주차)`처럼 미리보기).
   - **회차 카드**: 지금 회차(`1차`·`2차`…)와 Day, 지난 회차 결과(달성률·몸무게·체지방 변화), **🔄 다음 회차(N+1차) 시작하기** 버튼
     - 튜토리얼 위쪽에 **"기록은 현재 기기 브라우저에 자동 저장돼요. 같은 기기에서 다시 열면 그대로 이어져요."** 안내가 있어요.
     - **여성**을 고르면 **생리주기 입력**이 열립니다: 최근 생리 시작일(YYYY-MM-DD) · 평균 생리 주기(기본 28일, 21~45일) · 평균 생리 기간(기본 5일, 2~10일). **남성**을 고르면 이 입력란과 앱의 모든 생리주기 UI가 숨겨집니다.
   - **02 기본 규칙**: 14시간 공복 · 7시간+ 숙면 · 의자 중독 탈출 · 운동 강도(4가지) + 나머지 공통 수칙 접이식
   - **단백질 기준**: 단백질쉐이크 선택 기준(순탄수 15g↓ · 당류 3g↓ · 단백질 20g↑)과 하루 단백질 섭취 권장량(소제목 바로 아래 `현재 체중 00.0kg 기준`, 0.8g / 1.2~1.6g / 최대 2g per kg) 자동 계산
   - **03 전 주차 금기식품**: 🍭 설탕·청량음료 🍺 술 … **이모지 + 글씨 칩**, 항목별 상세는 접이식
   - **04 주차별 허용식품**: D1~3 / D4~7 / 2주차 / 3주차 / 4주·유지기 허용식품 이모지 칩 + **외식 추천 메뉴**
     - 밥은 **`밥 2/3공기 (백미·현미·잡곡 모두 가능)`**, 4주차는 **점심 `일반식 · 밥 1공기 (탄수 제한 없이 · 백미·현미·잡곡 가능)` · 저녁 `저탄수식 · 밥 2/3공기 (백미·현미·잡곡 가능)`**으로 표기하고, 해당 주차 안내에 **"당뇨가 없다면 현미·잡곡뿐 아니라 흰쌀밥도 같은 양으로 드셔도 돼요."** 한 줄을 함께 보여줘요(보드 주차 블록·오늘 화면 식단 안내에도 동일).
1. **오늘** — 한 화면 대시보드
   - **히어로(프로필·신체 요약)**: 닉네임과 **회차 뱃지(1차·2차…)** — 그 아래 줄은 `1주차 · 11월 25일 (수) · 오늘`처럼 회차·주차·날짜만 보여주고 **본명(데모 이름)은 표시하지 않습니다**. **몸무게(kg)·골격근량(kg)·체지방량(kg)·내장지방레벨** 4항목(좁은 화면은 2×2, 넓은 화면은 한 줄), 28일 달성률 줄무늬 게이지, Day/주차
     - 게이지 위를 **통통한 요가복(크롭탑+레깅스) 캐릭터가 현재 % 위치에서 달려가고**, 끝에는 결승 깃발(100%면 트로피)이 있어요. 캐릭터는 인라인 SVG라 이미지 파일 없이 가볍게 동작합니다.
   - **실시간 타이머(1초 갱신)**: 공복 타이머(14시간 기준, 전날 마지막 식사 시각 수정 가능) · **아침 먹었어요 ✓**(그 시점까지 실제 공복 시간을 `공복 14시간 15분 완료 · 08:15 아침 식사`처럼 고정 표시, 시각 수정·해제 가능 — 단식일 카드에서는 같은 버튼이 **단식 종료**로 계산·표시) · **단식일 24시간 단식 타이머**(전날 마지막 식사 기준 → 24시간 카운트다운, 18시간 최소 기준 통과 표시, 24시간 달성 시 🏆 · 게이지 캐릭터 100%) · **마지막 저녁식사 타이머**(취침 2시간 전 쉐이크 / 4시간 전 무탄·저탄 일반식 — 카드에서 탭 한 번으로 전환, 선택은 저장됨. 1주차 D1~7 기본은 쉐이크, 2~4주차는 일반식) · **저녁 식사 시작했어요 ✓**(누르면 그 시각이 `entries[day].lastMealAt`·`settings.lastMeals[day]`에 저장되어 **다음 날 14시간 공복·24시간 단식 타이머가 그 시각부터** 계산) · 수면 카운트다운(최소 7시간, 내일 기상 목표 수정 가능, 권장 취침 시각 표시) — 세 게이지 위에서도 캐릭터가 초침에 맞춰 이동
   - **모든 날짜에서 타이머 3개 상시 표시**: `‹`/`›` 또는 보드에서 다른 날을 열어도 공복(단식일이면 24시간)·마지막 저녁식사·수면 카드가 항상 함께 뜹니다. 오늘이 아닌 날짜에서는 지금 시간 기준으로 계산된다는 안내가 붙어요.
   - **단식일 전날 '단식 시작하기' ⏱️**: 단식일 하루 전 화면의 공복 카드에 **`⏱️ 내일 단식일 · 단식 시작하기`** 버튼이 떠요. 아침 쉐이크 후·점심 후·저녁 후 원하는 시점에 누르면 **그 순간의 시각이 다음 날 24시간 단식의 시작 시각**으로 저장되고(`settings.fastStarts[단식일]`), 전날 화면에도 `13:20부터 단식 시작됨`으로 표시돼요. 시각은 직접 고칠 수 있고 **`단식 시작 취소`**로 되돌릴 수 있어요. 단식일 당일에는 저장된 시작 시각을 **가장 먼저** 기준으로 잡아 `전날 13:20 단식 시작 → 오늘 13:20까지 (24시간)`로 계산하고(18시간 최소 기준 포함), 누르지 않았을 때만 전날 마지막 식사 시각(`entries[전날].lastMealAt` → `settings.lastMeals[전날]` → 기본 18:00)을 써요.
   - **단식일 바꾸기**: 단식일 카드의 `단식일 바꾸기`(또는 상단 Day 표시줄)에서 같은 주차의 다른 날로 하루 단식일을 옮기거나 해제할 수 있어요. 옮기면 **원래 날짜는 일반 식단(14시간 공복 타이머)**으로 돌아가고 **새 날짜에 24시간 단식 타이머가 바로** 뜹니다. 연속 이틀 단식이 되면 한 번 더 확인해요.
   - **주차별 조언 카드**: 날짜표시줄 아래에 그 주차의 조언·주의사항이 카드로 떠요. 1주차(1~7일차)에는 ①1~3일차는 가급적 **단백질쉐이크만** ②1주차 인바디는 **체지방 증가·골격근량 감소**로 보일 수 있으니 숫자에 연연하지 않기 ③두통이 심하면 **타이레놀** 복용 가능 ④영양제는 **4일차 이후, 공복이 끝난 뒤** 섭취를 안내합니다. **8일차**에는 결과와 상관없이 2주차 진행 + 3~14일차 감량 정체 안내, **15일차**에는 골격근 회복·체지방 감소면 3주차 진행 / 근손실 지속이면 2주차 반복 + **이틀 연속 단식 금지**(월·목 ○, 월·화 ✕), **22일차**에는 4주차 진행 / 3주차 반복 / 2주차 반복 판단과 완주 후 플랜(3주 이상 유지기 후 스위치온 재시작 또는 유지기 없이 3주차 식단 유지)을 보여줘요. 분기일(8·15·22일차)에는 `오늘 분기일` 배지가 붙습니다.
   - **오늘의 생리주기 배지**: 여성이고 최근 생리 시작일을 넣었으면 날짜 표시줄 아래에 `✨ 황금기 · 감량 최적기` `🌸 생리전 정체기 · D-2 (붓기 주의)`처럼 **오늘의 주기 단계 배지 + 한 줄 안내**가 떠요. 시작일이 비어 있으면 `🌈 생리주기 미입력` 안내만 보여줍니다(남성은 미노출)
   - **오늘의 명언**: Day 1~28에 맞춰 자동으로 바뀌는 확언·실전 조언 28개
   - **허용식품 / 금기식품**: 이 주차의 허용식품과 핵심 금기식을 **보드의 주차 블록**에서 초록·빨강 카드로 구분해 `🥬 양배추·채소` `🍚 밥 2/3공기 (백미·현미·잡곡 모두 가능)` / `🍭 설탕·청량음료` `🍺 술(한 모금도 X)`처럼 **이모지 + 짧은 글씨 칩**으로 표시(튜토리얼 탭 전체 보기 연결)
   - **오늘의 7가지 퀘스트**: 아침·점심·오후간식·저녁·물(2L/8잔, 카드에서 +1잔)·운동(웨이트 20분+/유산소 40분+)·수면(7시간 이상) 카드를 눌러 완료. 카드마다 파스텔 컬러 이모지 배지(🌅·🍚·🍎·🌙·💧·🏃‍♀️·😴)와 진행률 게이지 위 캐릭터가 있어요. 단식일 끼니는 '단식'으로 자동 완료
   - **인증사진**: 아침·점심·오후간식·저녁·운동 카드에서 촬영/선택 → 자동 리사이즈·압축 + 우측 하단에 촬영 시각·항목명 타임스탬프, 썸네일·크게 보기·다시 찍기·삭제
   - **세부 기록(접이식)**: 끼니별 계획/체크, 아침·저녁 영양제, 물 8잔 카운터, 공복 14시간·수면·운동·생리·대변
   - **운동 비고(자유 입력)**: 운동 줄 바로 아래 비고란에 `유산소 종류·시간, 웨이트 시간`을 자유롭게 적으면 그 날짜 기록(`entries[날짜].exercise.note`)에 자동 저장되고, 날짜를 오가거나 새로고침해도 유지돼요. 관리자 참여자 상세의 일별 기록 표·CSV(`운동 메모`)에서도 확인할 수 있어요.
   - **인바디 입력**: 측정 날짜, 몸무게·골격근량·체지방량·내장지방레벨
   - 메모, 관리자 피드백 (오늘 화면에는 추천템 배너가 없고, 추천템은 하단 `추천템` 탭에서만 봐요)
2. **보드** — 28일 전체 체크보드. 1주차는 **1~3일차 / 4~7일차(1주차)** 두 블록으로 나뉘고, 5개 블록 각각에 **미션 요약 + 그 주차 허용·금기식품 칩 + 체크 그리드**가 함께 들어갑니다. 주차별 조언·분기 안내는 `오늘` 탭에만 두어 보드를 깔끔하게 유지해요.
   - 각 주차 블록 **상단에 그 주차의 핵심 미션 · 식단 · 단식 · 운동 요약** (1주차는 D1~3 / D4~7 두 블록, 2·3·4주는 해당 주차 요약)
   - 주차마다 **이 주의 단식일**(지금 지정된 날짜 기준)과 **단식일 바꾸기** 버튼 — 여기서도 같은 주차 안에서 단식일을 옮길 수 있어요
   - 상태 색상: **완료(초록)·일부/미달(코랄)·미입력(점선 코랄)·예정(회색)**, 오늘은 굵은 테두리
   - 각 칸 아래 6칸 스트립 = **식단·물·영양제·공복·수면·운동** O/X (초록 O, 코랄 X, 회색 미입력)
   - 주차 보기에서는 일자별 카드에 항목별 O/X 그리드 표시
3. **인바디** — 주차별 인바디(몸무게·골격근량·체지방량·내장지방레벨 4종 변화 카드·SVG 추이 그래프·입력). **4개 그래프 모두** 점 위에 실제 수치(예 `61.5`)를 작게 표시하고, **각 그래프 x축 주차 라벨 아래에 해당 측정일/주차 기준일**(예 `11.25`)을 함께 적어요. 탭 맨 위에는 **인바디 마인드 조언 카드**(💡 *매일 몸무게는 잠깐 쉬어가요* — 매일 몸무게를 재지 않도록 노력해요! 일희일비는 다이어트의 적이에요)가 있어요.
   - 시작(1일차)·1~4주차 입력, 시작 대비 변화 카드(4종), "주 1회 권장·단식일 다음날 제외" 안내
   - **생리주기 연동**: 시작·1~4주차 입력 행과 그래프 영역에 그 시점의 **주기 단계 배지**(`🌸 정체기 D-2` 등)를 함께 표시하고, **"생리 직전에는 수분 정체로 체중·체지방이 일시적으로 정체되거나 올라갈 수 있어요"** 안내를 붙입니다. 여성·시작일 입력 시에만 보여요.
4. **🏆 28일 최종 리포트** (`보드` 탭 상단 · `인바디` 탭 하단 · 28일차 오늘 탭 축하 배너에서 열림)
   - **최종 요약**: 28일 전체 달성률 · 완료한 날(모든 항목 100%) · 완료한 퀘스트 수 · 최장 연속 달성일 · 단식 완료 횟수
   - **최종 인바디 변화**: 시작 → 최신(4주차) 몸무게 · 골격근량 · 체지방량 · 내장지방레벨 변화량
   - **주차별 결과**: 1~3일차 / 4~7일차 / 2주차 / 3주차 / 4주차의 루틴 달성률(%) + 그 주차 인바디·변화
   - **잘 지킨 루틴 vs 아쉬웠던 루틴**: 아침·점심·오후간식·저녁·물·운동·수면·단식 항목별 달성률을 계산해 잘 지킨 항목과 놓치기 쉬웠던 항목을 나눠 보여주고, 격려 코멘트를 붙입니다(전체 8개 달성률은 접이식으로).
   - **유지기 가이드(4주 종료 후 최소 3주)**: ①언제 유지기로 넘어가는지 ②유지기 핵심 루틴(공복 14:10 · 단식 주 0~1회 · 클린식 + 치팅 주 1회 한 끼 · 치팅 다음 날은 클린식 ➡️ 단식 · 운동 주 4회 이상 · 수면 7시간/물 2L) ③유지기 음식 리스트(박용우 교수님 기준 요약)를 리포트 하단에 정리했어요.
   - **📷 리포트 이미지 저장(PNG)**: 외부 라이브러리 없이 브라우저 Canvas로 요약 카드(달성률 요약 · 인바디 · 잘 지킨/아쉬운 루틴 · `@yoyop_diet` 표기)를 그려 PNG로 다운로드합니다. 진행 중에도 미리 볼 수 있어요. 저장 파일명에는 회차가 붙어요(`…_2차_28일최종리포트_…png`).
   - **🔄 회차 누적(1차 · 2차 · N차)**: 28일을 한 회차로 보고, 리포트에서 **다음 회차(N+1차) 시작하기**를 누르면 ① 지금 회차의 28일 기록·인바디·일별 기록·피드백을 **삭제하지 않고 `rounds` 아카이브에 그대로 보관** ② 닉네임·성별·생리주기 설정과 **직전 최신 인바디**를 이어받아 ③ 새 시작일(기본 오늘, 과거·미래 선택 가능)로 **N+1차 Day 1**을 깨끗하게 시작합니다. 리포트 상단의 **회차 탭(`1차 결과` / `진행 중 2차` …)** 으로 지난 회차 리포트를 언제든 다시 열 수 있고, 2회차부터는 **회차 누적 비교 표**(회차별 기간 · 달성률 · 몸무게 · 체지방 변화)가 함께 보여요.
5. **추천템** — 한 화면을 **공구 / 쿠팡 / 광고** 3개 섹션으로 나눠 보여줍니다(상단 필터로 한 종류만 볼 수도 있어요).
   - **공구**는 **일정순** 정렬: 진행 중인 공구는 **마감 임박한 순**, 시작 전 공구는 시작이 빠른 순, 끝난 공구는 뒤로. 카드마다 `11.20~11.25 · D-1 마감`처럼 기간과 남은 날짜를 표시해요.
   - **쿠팡**은 **쉐이크 → 식단템 → 운동템 → 기타** 4개 하위 카테고리로 묶어서 순서대로 보여주고, 하위 카테고리 칩으로 하나만 골라볼 수 있어요.
   - **광고**는 브랜드 광고 카드입니다.
   - **쿠팡 파트너스 고지**: 쿠팡 카드와 쿠팡 링크가 들어간 카드에는 `쿠팡 파트너스 활동의 일환으로, 이에 따른 소정의 수수료를 제공받습니다.` 문구가 **항상** 표시됩니다(관리자 토글과 무관).

> 기존의 **가이드 탭은 없어졌어요.** 공통 규칙·단백질 기준·금기식·주차별 허용식품·외식 추천은 **튜토리얼 탭**으로, 주차별 핵심 안내(미션·식단·단식·운동)는 **보드의 주차 블록**으로 옮겼습니다.
> D1~3 당질 제한(10시간 내 쉐이크 4회·탄수/과일/콩/견과/카페인 제한), D4~7 밥 2/3공기(백미·현미·잡곡 모두 가능) 점심과 영양제, 2주차 간헐적 단식+HIIT, 3주차 단식 2회·활동량 UP, 4주·유지기(점심 일반식·밥 1공기, 저녁 저탄수식·밥 2/3공기, 과일 1개)는 보드 요약과 오늘 화면 안내에 그대로 담겨 있습니다.

- `entries`는 **프로그램 Day(1~28)** 기준입니다. `date`는 인바디 측정 날짜 표시용.
- 단식일 24시간 타이머는 **그 날의 전날 기록**에서 마지막 식사 시각을 가져옵니다: `entries[day-1].lastMealAt` → `settings.lastMeals[day-1]` → `settings.fastPrevMealAt` → 기본 `18:00`. 카드에서 고친 시각은 `settings.fastPrevMeal[day]`에 그 날짜에만 저장돼요.
- `visceral`은 내장지방레벨(숫자), `photos`는 항목별 인증사진(압축된 JPEG 데이터 URL + 촬영 시각)입니다.
- 달성률 = 계획된 끼니(단식 제외) + 영양제 2(단식일 제외) + 물(8잔까지 부분점수) + 공복 + 수면 + 운동 + 대변. 생리는 기록만 하고 점수에서 제외.
- 최종 리포트의 `최장 연속 달성`은 **모든 항목을 채운 날(달성률 100%)** 이 며칠 연속인지로 계산하고, 100%인 날이 없으면 기록 연속일로 보여줘요. 항목별 달성률은 계획된 날만 분모에 넣습니다(단식일엔 식사·단백질 제외).
- 주차 인바디 = 그 주의 마지막 측정값. **단식일 다음날 측정값은 집계에서 제외**(수분 영향).

RLS 예시 (참여자는 본인 기록만, 관리자는 전체):
```sql
alter table participants enable row level security;
alter table entries enable row level security;

create policy "own participant" on participants
  for select using (auth_user_id = auth.uid());

create policy "own entries" on entries
  for all using (
    participant_id in (select id from participants where auth_user_id = auth.uid())
  );

create policy "admin all" on participants
  for all using (auth.jwt() ->> 'role' = 'admin');
```

## 9. 인증사진 처리 방식

1. 퀘스트 카드의 `인증사진`(또는 `다시 찍기`)을 누르면 `<input type="file" accept="image/*" capture="environment">`가 열립니다.
2. 선택/촬영한 사진을 `js/photo.js`가 HTML5 Canvas로 그리며 **긴 변 900px 이하**로 줄이고,
   JPEG 품질을 0.82 → 0.42까지 낮춰 **약 80KB 이하**가 되면 저장합니다(그래도 크면 한 번 더 축소).
3. 같은 캔버스 오른쪽 아래에 **`2026.11.24 08:32 · 아침`** 형식의 반투명 타임스탬프를 찍습니다. (기기 로컬 시각)
4. 결과는 `entry.photos[항목]`에 `{ dataUrl, at, label, w, h, bytes }`로 저장되고, 카드 썸네일·크게 보기(촬영 시각·용량·해상도 표시)·삭제가 가능합니다.
5. 관리자 참여자 상세의 **인증사진** 갤러리에서 일자·항목·촬영 시각과 함께 확인할 수 있습니다(관리자는 열람만).
